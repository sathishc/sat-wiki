# Trusted System

The external repository where every open loop, commitment, task, and project lives — outside the brain. The core infrastructure of [GTD](./gtd-workflow.md).

## What Makes a System Trusted

A system earns trust when it has four properties:

| Property | Meaning |
|----------|---------|
| **Complete** | Everything is in it — nothing held in memory |
| **Current** | Regularly reviewed and updated |
| **Accessible** | You can see all relevant options when choosing what to do |
| **Unambiguous** | Each item has a clear next action |

If any property fails, the brain stops trusting the system and starts rebuilding its internal tracking — recreating the anxiety GTD was designed to eliminate.

## The Problem It Solves

The human brain is poor at storing commitments reliably. It resurfaces them at random, inappropriate times (reminding you to call the dentist while you're in a meeting), and fails to surface them when relevant. This creates:
- **Cognitive overhead** — background processing consuming attention
- **Anxiety** — the feeling that something is being forgotten
- **Reactivity** — responding to the loudest input rather than the most important

A trusted system offloads all of this. Once fully externalised, the brain relaxes into [mind like water](./mind-like-water.md).

## Components

A minimal trusted system needs:
- **Inboxes** (capture tools) — where new inputs land
- **Next Actions lists** — organised by [context](./contexts-gtd.md)
- **Projects list** — all multi-step desired outcomes
- **Calendar** — hard landscape (time/day-specific only)
- **Waiting For list** — delegated items
- **Someday/Maybe list** — deferred intentions
- **Reference filing** — non-actionable information

The tools (physical, digital, hybrid) don't matter. Discipline does.

## Trusted System vs Productivity App

Most productivity apps are not trusted systems. They fail because:
- Inboxes double as task lists
- Items sit un-clarified ("write blog post" instead of "open Notion and draft outline")
- No weekly review habit → lists stagnate
- Calendar overloaded with non-hard-landscape items

GTD can be implemented in a paper notebook; it can also collapse in the most sophisticated app if the discipline is absent.
